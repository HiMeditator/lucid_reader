# Lucid Reader 开发进度规划

本文档用于跟踪开发阶段、技术验证和 MVP 验收状态。功能规划见 [FEATURES.md](./FEATURES.md)，架构规划见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 1. 当前状态

产品规划已拆分为总览、功能、架构和进度四份文档。当前项目仍处于工程基础启动前，后续实际开发任务从“近期行动项”和“阶段 0：工程基础”开始跟踪。

## 3. 技术选型待验证 TODO

- [ ] 验证 Flutter EPUB 渲染方案是否能满足目录、选区、样式和位置映射。
- [ ] 验证 Flutter PDF 方案是否能同时满足显示、文本提取和选区。
- [ ] 验证 Windows 与 Android 上本地数据库、全文检索和向量检索的性能。
- [ ] 验证本地 TTS 模型在 Android 设备上的体积、速度和分发方式。
- [ ] 验证 Ollama 在 Windows 上的服务发现、模型列表和错误处理体验。
- [ ] 验证大文件解析放入 isolate 后的数据传输成本。
- [ ] 验证向量索引先用 SQLite 扩展、纯 Dart 实现，还是使用平台原生库。
- [ ] 验证 Flutter 本地化资源结构、系统语言跟随和运行时切换在 Android 与 Windows 上的行为。

## 5. MVP 完成定义

- [ ] Android 和 Windows 可运行。
- [ ] 界面初始支持英语、中文、日语，并能通过新增本地化资源扩展更多语言。
- [ ] 可以导入并阅读 TXT、EPUB、PDF，MOBI 有实验入口或明确提示。
- [ ] 可以保存阅读进度和基础阅读设置。
- [ ] 可以配置至少一个 OpenAI 兼容 Provider 和一个 Ollama Provider。
- [ ] 可以对选中文字进行翻译、总结、解释。
- [ ] 可以对当前书籍启用段落级双语阅读，并复用翻译缓存。
- [ ] 可以为当前书籍建立语义索引并进行问答。
- [ ] 问答答案包含可跳转引用。
- [ ] 可以使用至少一种 TTS 方式朗读文本。
- [ ] 没有模型配置时，基础阅读功能仍然完整可用。
